# Freqtrade for YunoHost

Freqtrade is a free and open source crypto trading bot written in Python. It is designed to support all major exchanges and be controlled via Telegram or webUI.

## Features

- **Paper Trading**: Test your strategies with paper trading (dry-run mode)
- **Strategy Development**: Write custom trading strategies in Python
- **Backtesting**: Test strategies against historical data
- **Live Trading**: Execute trades on real exchanges
- **Web Interface**: FreqUI web interface for monitoring and control
- **Telegram Integration**: Control bot via Telegram
- **Multiple Exchanges**: Support for major crypto exchanges

## Default Configuration

- **Dry-run mode**: Enabled by default for safety
- **Web Interface**: Accessible at your chosen path
- **Default strategies**: Simple buy/sell strategies included
- **Security**: JWT authentication for web interface

## Important Notes

- **Start in dry-run mode**: The bot is configured to run in paper trading mode by default
- **Configure your exchange**: You need to set up API keys for your chosen exchange
- **Strategy development**: Write your own strategies or use community strategies
- **Risk warning**: Cryptocurrency trading involves risk of loss

## First Steps

1. Access the web interface at your domain/path
2. Login with your YunoHost credentials
3. Configure your exchange API keys
4. Test with dry-run mode first
5. Develop or import trading strategies
